# Jeomseon Unity Grid Tile System

A Unity package for hex coordinates, tile data and interaction, and URP decal-based grid visualization.

## Requirements

- Unity 2022.3 or newer
- Universal Render Pipeline 14.0.11 or newer
- The `com.jeomseon.unity` scope configured for the OpenUPM registry

## Install

Add `com.jeomseon.unity.grid-tile-system` by name in Unity Package Manager. Before the OpenUPM release is available, use:

```text
https://github.com/jeomseon0516/Unity.GridTileSystem.git#v0.1.0
```

Unity's built-in 2D Hexagonal Tilemap may be a better fit for conventional 2D tile games. This package targets 3D world-space surfaces, physics raycasts, URP decals, and per-tile runtime state.
